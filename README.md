PROMPT RIG プライバシーポリシー
更新日：2026年10月3日

提供者：WAKO（制作者名：ゔぁるペす）

1. アプリ内で扱うデータ
PROMPT RIGは、ユーザーが入力・読み込みした文章、カテゴリ、項目、出力先、生成結果および設定を、プロンプトの整理・組み立てと作業状態の保存に使用します。これらのデータは、ユーザーのPC内に保存されます。

現在の版には、登録内容を提供者のサーバーへ自動送信する機能、広告配信、アクセス解析、独自のアカウント登録機能はありません。

2. ファイルとクリップボード
JSONの読み込みでは、ユーザーが選択したファイルを処理します。JSON保存では、アプリ内のデータを書き出します。コピー操作では、対象の生成結果をクリップボードへ書き込みます。

書き出したJSONやコピーした文章を他者・外部サービスへ渡す場合、その内容を事前に確認してください。

3. 保存・削除とバックアップ
ユーザーはアプリ内で登録内容を確認・編集・削除できます。削除や初期化などの前には、復元用の直前バックアップがPC内に保存されるため、操作前の内容が残る場合があります。

アプリ内の初期化は、直前バックアップや設定を含むすべての保存情報の完全消去を意味しません。また、書き出したJSONファイルは自動では削除されません。保存情報の完全削除方法については、下記の連絡先へお問い合わせください。

保存データやJSONには、アプリ独自の暗号化・パスワード保護を設けていません。PCや保存先へのアクセスを適切に管理してください。

4. お問い合わせ
ユーザーがメールやXで問い合わせを送信した場合、提供者は送信元のメールアドレス・アカウント名、問い合わせ本文、添付資料などを受け取ります。

これらは問い合わせ対応、不具合調査および改善のために必要な範囲で使用し、対応に必要な期間保管します。不要になった情報は削除します。法令に基づく場合を除き、本人の同意なく第三者へ提供しません。

問い合わせ情報の確認・訂正・削除を希望する場合は、下記へご連絡ください。

5. 外部サービス
問い合わせリンクからメールアプリやXを開いた場合、それぞれのサービスのプライバシーポリシーが適用されます。Microsoft Storeによる配布や更新などに伴う情報の取り扱いは、Microsoftのプライバシーに関する声明をご確認ください。

6. ポリシーの変更
機能や情報の取り扱いを変更する場合は、本ポリシーを更新してお知らせします。
